# 急救诊疗助手 v0.2（交互原型）

这是“基层用药助手”仓库中的独立实验目录，用于验证一个面向基层急诊/抢救场景的网页工作台。它不会替换仓库根目录现有应用。

## 当前已完成

- 响应式首页与移动端底部导航
- 急救工作台：急症处置、抢救用药、急救流程、计算工具、急诊病历、待办
- 红旗入口：无反应、严重呼吸困难、休克、抽搐/意识障碍、严重过敏、大出血/创伤、胸痛高危、中毒
- “按主诉 / 按诊断”双入口
- 全局搜索：主诉、诊断、药物、流程、工具、病历模板
- 抢救药物结构化详情字段（临床数值默认锁定）
- 流程卡结构
- 通用输液滴速演示工具
- 结构化急诊病历骨架生成
- LocalStorage 值班待办
- 内容核验状态提示

## 安全边界

本目录当前是产品交互原型，不是临床决策系统。药物剂量、给药途径、稀释方式、评分规则、治疗阈值和具体诊疗流程在正式上线前必须：

1. 绑定权威指南或药品说明书来源；
2. 标注版本与更新时间；
3. 由临床人员逐项审核；
4. 高风险字段保留醒目提示与复核机制；
5. 涉及患者数据时另行设计权限、隐私、审计与数据安全。

## 本地运行

直接打开 `index.html` 即可，或用任意静态服务器托管本目录。
